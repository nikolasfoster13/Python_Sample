# Making Faces
faces.py contains a function called "convert" that accepts a string as input and returns the same input with any :) converted to 🙂 (otherwise known as a slightly smiling face) and any :( converted to 🙁 (otherwise known as a slightly frowning face). All other text should be returned unchanged.

In the same file, a function called "main" prompts the user for input, calls convert on that input, and prints the result.
