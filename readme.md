# Meal Time
meal.py is a program that prompts the user for a time and outputs whether it's "breakfast time", "lunch time", or "dinner time". If it's not time for a meal, the program doesn't output anything at all. The program assumes that the user's input will be formatted in 24-hour time and assumes that each meal's time range is inclusive.

Meal times are:
* Breakfast: 7am - 8am
* Lunch: 12pm - 1pm 
* Dinner: 6pm - 7pm
