# Tip Calculator
tip.py is a Python program that works as a tip calculator. 

The dollars_to_float funciton accepts a string as input (formatted as $##.$$), removes the leading "$", and returns the amount as a float.

The percent_to_float fuction accepts a string as input (formatted as ##%), removes the trailing "%", and returns the percentage as a float.

The main function prompts user for the cost of the meal & the percentage they'd like to tip before reutrning the tip amount.
