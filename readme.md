# Felipe's Taqueria
One of the most popular places to eat in Harvard Square is Felipe’s Taqueria, which offers a menu of entrees.

taqueria.py is a program that enables a user to place an order, prompting them for items, one per line, until the user inputs ctrl+d. After each inputted item, the program displays the total cost of all items in the order, prefixed with a dollar sign ($) and formatted to two decimal places. Each user's input is treated case insensitvely and ignores any input that isn't on the menu.
