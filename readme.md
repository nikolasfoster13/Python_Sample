# Emojize 
Because emojis aren’t quite as easy to type as text, at least on laptops and desktops, some programs support “codes,” whereby you can type, for instance, :thumbs_up:, which will be automatically converted to 👍. Some programs additionally support aliases, whereby you can more succinctly type, for instance, :thumbsup:, which will also be automatically converted to 👍.

emojize.py is a program that prompts the user for a string in English and then outputs the "emojized" version of that string, converting any codes thein to their corresponding emoji.
