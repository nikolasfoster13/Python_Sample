# Math Interpreter
interpreter.py is a program that prompts the user for an arithetic expression and hen calculates and outputs the result as a floating-point value formatted to one decimal place. The program assumes that the user's input will be formatted as "x y z", with one space between x and y and one space between y and z, wherein:

* x is an integer
* y is +,-,*,or /
* z is an integer
